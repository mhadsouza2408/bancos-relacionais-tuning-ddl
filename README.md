# 🗄️ Arquitetura, DDL e Tuning em Bancos Relacionais

Este repositório consolida meus projetos e scripts avançados em Bancos de Dados Relacionais (Oracle, PostgreSQL e MySQL). O objetivo é demonstrar boas práticas de modelagem física de dados e otimização de performance (Query Tuning).

## 📂 Estrutura do Repositório

- **Oracle/**: Scripts PL/SQL, particionamento de tabelas e análise de planos de execução.
- **PostgreSQL/**: Modelagem de dados, criação de índices estratégicos e otimização de queries analíticas.
- **MySQL/**: Procedures, functions e tuning de consultas para sistemas transacionais.

## 🚀 Metodologia de Tuning
Nos diretórios de `Performance_Tuning`, as otimizações são documentadas demonstrando a redução de custos através de:
1. Reescrita de queries sub-otimizadas.
2. Criação de índices (Compostos, Cobertura, Filtrados).
3. Comparação direta de **Explain Plans** (Antes x Depois) mitigando gargalos de Full Table Scans.
